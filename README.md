# ML Practical Notebooks

This workspace contains Jupyter notebooks for machine learning practicals.

## How to run

1. Open a terminal in this folder:

```bash
cd "/Users/harshvardhanvijayhajgude/Quantum Coders/ML/ML Praticals"
```

2. Activate the virtual environment:

```bash
source .venv/bin/activate
```

3. Start Jupyter Notebook or JupyterLab:

```bash
jupyter notebook
```

or

```bash
jupyter lab
```

4. Open the notebook you want to run, such as `hwq1.ipynb`, and run the cells in order.

## Files

- `hwq1.ipynb` - Linear regression example using temperature and ice cream sales data.
- `hwq2.ipynb` - Second practical notebook.
- `demo.ipynb`, `demo2.ipynb` - Demo notebooks.
